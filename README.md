# בנק הודעות חירום

אפליקציית PWA מותאמת לנייד להכנת הודעות חירום לציבור, על בסיס בנק תבניות רשמי לרשות
מקומית (75 תבניות ב-19 קטגוריות אירוע). האפליקציה **מנסחת** הודעה בלבד — היא לא שולחת דבר
בעצמה ולא מתחזה לגורם רשמי; השליחה בפועל תמיד דרך המשתמש, בערוץ ההפצה הרשמי שלו (למשל
וואטסאפ).

## מה יש בפנים

- **75 תבניות** (68 ממוספרות + 7 הודעות כריזה) ב-**19 קטגוריות**: שינוי מצב/חירום, ירי
  טילים, זירות פגיעה, פינוי וקליטה, מיגון ומקלטים, חשמל, מים ומזון, תקשורת והתרעות, שריפה,
  חומ"ס, רעידת אדמה, חינוך/עבודה/שירותים, שמועות ומידע שגוי, מתנדבים, התאוששות, חדירת
  מחבלים, כטב"ם, שיטפונות, והודעות כריזה
- **שדות קבועים אוטומטיים**: שם הרשות ומספר המוקד נשמרים פעם אחת במסך ההגדרות וממולאים
  אוטומטית בכל הודעה; תאריך ושעה מתעדכנים אוטומטית לפי מועד ההכנה
- **שדות פרטניים לפי תבנית**: מזוהים אוטומטית מתוך הסוגריים המרובעים שבתבנית המקורית; שדות
  "מלל חופשי" חוזרים (`___`) מזוהים כל אחד בנפרד ומתויגים לפי ההקשר שלהם בטקסט
  (`src/lib/templateEngine.ts`)
- **תצוגה מקדימה חיה** עם סימון ברור של שדות שטרם מולאו
- **בקרת איכות לפני הפצה** — 8 הסעיפים מהנספח הרשמי, חובה לאשר את כולם לפני שיתוף
- **שיתוף לוואטסאפ** (Web Share API / `wa.me`) או העתקת טקסט ללוח
- **היסטוריה** של הודעות שהוכנו במכשיר, **עקרונות שימוש** כמסך מידע
- עברית מלאה, RTL, מובייל-first, PWA (ניתנת להתקנה, עובדת גם אופליין)

## הרצה מקומית

```bash
npm install
npm run dev
```

## בדיקות ואימות

```bash
npm test    # בדיקות מנוע התבניות (Vitest)
npm run build
```

## פריסה

נפרס אוטומטית ל-GitHub Pages בכל push ל-`main` (ראו `.github/workflows/deploy.yml`).

## מבנה הקוד

- `src/data/templates.ts`, `categories.ts`, `checklist.ts`, `principles.ts` — תוכן בנק
  התבניות
- `src/lib/templateEngine.ts` — זיהוי שדות מתוך `[placeholder]` בטקסט התבנית והצבתם בחזרה
- `src/state/orgProfile.ts`, `history.ts` — מצב מקומי (`localStorage`)
- `src/screens/` — מסכי האפליקציה
